Personal technical interview prep

Gradient Path

One page per subject, built to be read in ten minutes before bed rather than studied for three hours on a Saturday. Every card leads with a picture and plain English, holds the precise version one switch away, and carries a prompt you can paste into any chatbot so the practice keeps going when you are away from here.

 

How to use this

  1. Do the one thing the path says. Do not open three modules.
  2. Read the picture before the words, every time.
  3. Mark each card honestly — fuzzy is the useful answer, not solid.
  4. Copy a card's prompt into ChatGPT or Gemini and let it quiz you while you work.
  5. Come back to the fuzzy ones tomorrow. That is the whole method.

Your path

    Why this order

    Nothing on the path leans on something further down it. The linear algebra comes before the transformer that uses it; the classical ML floor comes before the LLM stack that sits on top of it; and the production tiers come last because they are the first three pointed at a system that is actually serving traffic.

    The coding module runs alongside. It shares nothing with the rest, so slot it in whenever — one pattern a night is the intended pace.

    A stop turns solid when every card in it is marked solid. The marker moves to the first stop that is not finished, so it is always pointing at exactly one thing.

    Every card has a prompt

    Each topic, and each whole tier, carries a copy button that hands you a tutor prompt for ChatGPT, Gemini or Claude. It explains the concept first, makes you say it back before it moves on, walks the examples, then quizzes you one question at a time and scores you. Practise on a commute, in a queue, between meetings.

    Running it locally

    Keep every module file in the same folder as this page so the links resolve, then serve the folder with python3 -m http.server 8000 and open localhost:8000. Marks, theme and your Simple/Technical choice live in your browser's local storage — per browser, never uploaded anywhere.
